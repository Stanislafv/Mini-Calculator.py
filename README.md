# Mini-Calculator.py
Мини калькулятор на языке Python. В нём всего 20 строчек кода! Функционал: сложение, вычитание, умножение, деление, возведение в степень, удаление символов(последнего/всех) и скобки. Поддерживает составные выражения! Основан на принципе eval, но есть защита(Ввод происходит с графических кнопок)
